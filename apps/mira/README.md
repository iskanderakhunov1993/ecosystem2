# Mira App (`apps/mira`)

Мобильное веб-приложение Mira: женский health-трекер с шестью адаптивными
режимами и одной дизайн-системой. **База продукта** — сюда переносится зрелая
функциональность из `apps/web` (Next.js-версия).

## Стек

React 18 · TypeScript · Vite · Tailwind (тема на CSS-переменных) · Zustand ·
IndexedDB через `idb`. Роутинга нет — одна SPA-панель с двумя вкладками и
уровнями вглубь.

## Команды

```bash
npm install --prefix apps/mira
npm run dev --prefix apps/mira      # http://localhost:5180
npm run build --prefix apps/mira
npm run lint --prefix apps/mira     # tsc --noEmit
```

## Навигация

Две вкладки. Больше не значит лучше: у раздела должен быть свой вопрос
пользователя и своя частота открытия, иначе это экран внутри чужой вкладки.

**Сегодня** — «что со мной сегодня», ежедневно. Календарь неделей наверху,
кольцо с днём цикла и прогнозом, чипы быстрой записи, «записано сегодня»,
карточка тренировки и медитации.

**Мой цикл** — «это вообще нормально», раз в неделю-две. Прогноз со ступенью
уверенности, «что повторяется», метрики списком.

Второй уровень открывается по тапу: месяц календаря, детали прогноза (окно
фертильности, ПМС), полная аналитика с графиками. Третий — отчёт врачу.

Календарь живёт в «Сегодня», а не отдельной вкладкой: он нужен в момент
отметки. «Я забыла отметить позавчера» решается одним тапом, не уходя с экрана.
Тап по прошлому дню открывает его записи и даёт дозаполнить; запись ложится на
полдень выбранной даты. Будущие дни заблокированы — записи «наперёд» исказили
бы аналитику.

Аналитика, паттерны и прогнозы слиты в «Мой цикл»: для пользователя это один
вопрос, а три отдельные вкладки давали новому человеку три пустых экрана
подряд вместо одного честного.

## Структура

```
src/
  components/   Ring, Chip, BottomSheet, ConfidenceTag, Card, KpiCard,
                DonutStat, EmptyChartCard, Calendar (WeekStrip + MonthCalendar),
                Toggle, ProfileFields, AppShell
  features/     onboarding, today (+ LogSheet, WorkoutSheet, MeditationTab),
                cycle (объединённый экран), analytics, patterns, predictions,
                doctor (отчёт врачу), settings, life-stage-gate
  data/         modes.config.ts (life stages, поля онбординга, чипы лога,
                пулы тренировок), icons.tsx
  store/        appStore.ts (Zustand + запись в IndexedDB)
  db/           indexedDb.ts (схема и CRUD, запросы по диапазону дат)
  lib/          types.ts, derive.ts (расчёты цикла/срока/восстановления),
                safety.ts (красные флаги и триаж)
  styles/       tokens.css, index.css
```

`analytics`, `patterns` и `predictions` больше не вкладки — их экраны
переиспользуются как второй уровень внутри `cycle`.

## Ключевые продуктовые правила

- **Today = дашборд и ввод.** Тап по чипу открывает bottom sheet поверх Today;
  сохранение возвращает на Today. BottomSheet — единственный паттерн ввода.
- **Режим меняется только через Life-Stage Gate** (подтверждение жизненного
  события). Перименопауза — soft prompt, а не hard gate. Любое переключение
  можно отменить баннером на Today.
- **`logEvents` — единственный источник истины** для календаря, аналитики,
  паттернов и отчёта врачу. Лог append-only; «снимок» дня вычисляется из
  событий.
- **Честность вместо иллюзии точности.** Графики, паттерны и уверенность
  прогнозов зависят от реального количества записей; вместо моков —
  `EmptyChartCard` с объяснением, чего не хватает.
- **Никакой геймификации.** Ни стриков, ни бейджей: продукт иногда сам просит
  не заниматься, и счётчик серий с этим несовместим.
- **Локально-first.** Данные не уходят в облако; экспорт и полное удаление
  доступны в настройках.

## Отчёт врачу

Живёт блоком внизу «Моего цикла», а не вкладкой: его открывают раз в несколько
месяцев. Но счётчик собранных записей виден постоянно — иначе никто не узнает,
что документ копится, и бросит, не дойдя до главной ценности продукта.

Внутри: период выгрузки, блок «стоит обсудить» (собирается из `safety.ts` и
найденных паттернов, появляется только если есть что показать), факты цифрами
с пометкой отклонений, вопросы к приёму, выбор категорий и экспорт в текст.
Заметки своими словами и данные об интимной жизни сняты по умолчанию.

## Расчёты профиля

Профиль хранит введённые значения и `updatedAt`. Дашборд отсчитывает время от
этой точки, поэтому день цикла, срок беременности и дни после родов не
«замерзают» на дате регистрации. Перименопауза — сознательное исключение:
качественная метка без числового пересчёта.
