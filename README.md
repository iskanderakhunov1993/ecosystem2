# Livi — Знай свою норму

Приватный дневник женского здоровья: короткие ежедневные отметки превращаются
в понимание личной нормы и в документ, с которым можно прийти к врачу.

**Не диагноз, а дневник наблюдений. Не контроль, а забота. Не по памяти, а с фактами.**

Работа, на которую нанимают продукт, — не «отслеживать цикл», а **чтобы тебя
восприняли всерьёз**. Приём длится десять-пятнадцать минут, жалобы на боль
часто обесцениваются. Всё, что приближает момент «я пришла с доказательствами»,
приоритетнее остального.

---

## Быстрый старт

Приложение лежит в корне репозитория. Vite · React 18 · Zustand · IndexedDB · PWA.

```bash
npm install
npm run dev        # http://localhost:5180
npm run build
npm run lint       # tsc --noEmit
```

### `legacy/web` — предыдущая версия

Next.js-приложение, из которого переносится зрелая функциональность:
авторизация, анализы с референсами, контент-лента, синхронизация, партнёрский
доступ, исламский режим, подробный отчёт врачу. Собственный `package.json`,
в сборку продукта не входит.

Направление одностороннее: `legacy/web` → корень, не наоборот. Шесть режимов,
ступени уверенности и визуальный язык уже реализованы здесь, а перенести отчёт
и анализы дешевле, чем воспроизводить режимы заново. Чек-лист переноса —
[FEATURES.md](FEATURES.md).

## Навигация

Две вкладки. Критерий для вкладки — свой вопрос пользователя и своя частота
открытия.

**Сегодня** — «что со мной сегодня», ежедневно. Календарь неделей с точками
активности, кольцо с главным числом режима, чипы быстрой записи, «записано
сегодня», карточка тренировки.

**Мой цикл** — «это вообще нормально», раз в неделю-две. Прогноз со ступенью
уверенности, «что повторяется», метрики списком.

Второй уровень по тапу: месяц календаря, детали прогноза, полная аналитика с
графиками. Третий — отчёт врачу.

Профиль и приватность — шестерёнка в шапке. Переключение режимов — пилюля
слева вверху.

## Шесть режимов

Цикл · Планирую · Беременность · После родов · Перименопауза · Менопауза.

Одна система, шесть кож: layout, компоненты и паттерны взаимодействия
одинаковы, меняются акцентный цвет и содержимое. Режим переключается только
через Life-Stage Gate — подтверждение значимого события, а не свободный
тумблер.

## Ступени уверенности

Каждый вывод стоит ровно на одной из четырёх ступеней, и ступень вычисляется
из количества записей, а не задаётся вручную.

| Ступень | Что показываем |
|---|---|
| Нет данных | Пунктирная рамка и понятный следующий шаг |
| Мало данных | Полоса прогресса и точное число: «4 из 10» |
| Наблюдение | Вывод с исходной дробью: «3 цикла из 6» |
| Твоя норма | Утверждение с разбросом, а не одним числом |

Это главное отличие от конкурентов: они продают уверенность и промахиваются,
Livi честно говорит, когда не знает.

## Продуктовые правила

- **Один паттерн ввода** — bottom sheet, второй модалки быть не должно.
- **Честность важнее красоты** — пустое состояние это рабочее состояние системы, а не то, что маскируют.
- **Никакой геймификации** — ни стриков, ни бейджей: продукт иногда сам просит не заниматься.
- **Вкладка требует своего вопроса и своей частоты.**
- **Эскалация формулируется** как «стоит обсудить это с врачом», без диагнозов.

## Dev-сценарии `legacy/web`

В интерфейсе не должно быть слов «тест», «демо-пользователи» или предупреждений
о замене данных. Для проверки аналитики используется скрытый режим:
`http://localhost:4173/?debug=true` → страница «Аналитика» → блок
«Dev-сценарии аналитики».

| Сценарий | Что проверяет |
|---|---|
| Мало данных | Честное пустое состояние |
| Стабильный цикл | Аналитика без тревожных сигналов |
| ПМС-паттерн | Повторы тревоги и низкой энергии перед месячными |
| Для врача | Сильная боль, обильность, красные флаги |
| Забота влияет | Связь воды, ходьбы и веса с аналитикой |
| 45+ и анализы | Перименопауза, сон, сохранённые анализы |

## Бэклог

**Перенос из `legacy/web`** — анализы с референсами, контент,
напоминания, синхронизация, партнёрский доступ, исламский режим.

**Продукт** — скрининг на СПКЯ и эндометриоз (у Flo платный, попадает в ядровый
сегмент), выход из беременности без поздравлений, вариант «не помню дату» в
онбординге, экран «что было после приёма».

**Платформа** — PDF-экспорт отчёта, импорт из других трекеров, мобильное
приложение, монетизация.

Подробный разбор сегментов, сценариев и метрик — в [PRODUCT_SPEC](docs/PRODUCT_SPEC.md).
