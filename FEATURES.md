# Mira — полная опись функционала (`apps/web`)

Документ фиксирует **весь функционал `apps/web`** — предыдущей версии продукта.
Дизайн здесь сознательно не описывается: только логика и поведение.

**Зачем нужен сейчас.** Это чек-лист переноса. `apps/mira` — база продукта, и в
неё из `apps/web` предстоит перенести зрелую функциональность. Каждый пункт
отсюда должен получить одно из трёх решений: перенесён, сознательно выброшен
или отложен с причиной. Пока решение не принято по всем — перенос не закончен.

**Что уже перенесено или собрано заново в `apps/mira`:** отчёт врачу (упрощённо,
нативно под модель событий), красные флаги и триаж (`lib/safety.ts`), подбор
тренировки по самочувствию (`features/today/readiness.ts`), паттерны, аналитика,
приватность и удаление данных.

**Что ждёт переноса:** анализы с референсами, контент и статьи, напоминания,
синхронизация с Supabase, партнёрский доступ, исламский режим, возрастные
адаптации, геймификация (под вопросом — противоречит правилу об отсутствии
стриков).

**Что заведомо не переносится:** мёртвые компоненты, перечисленные в конце.

## 2. Навигация

6 вкладок (`types/navigation.ts`): Сегодня, Забота, **Отслеживать** (центральная кнопка — открывает
модалку быстрой отметки, не переход), Анализ, Контент, Профиль. Плюс глобальная плавающая кнопка
«🆘 Мне больно» → PainModal, доступная на всех экранах оболочки.

## 3. Хранилище данных

**Внимание: в приложении два параллельных слоя персистентности.**

### 3.1 Zustand-стор (`store/`, localStorage `mira-zustand-store`)
Middleware: `immer`, `devtools`, `persist` + валидация Zod при регидрации (`schema.ts`).
Персистятся `user/cycle/logs/care/settings`; `ui` сбрасывается.

- **user**: имя, возраст, email, месяцев наблюдения, всего циклов. → `setUser`, `updateTrackingStats`
- **cycle**: средняя длина, длительность месячных, дата последних месячных, список циклов, текущий
  день, фаза (`menstrual|follicular|ovulatory|luteal`), дней до месячных. → `setCycleLength`,
  `setPeriodLength`, `setLastPeriodStart`, `addCycle`, `updateCurrentDay`, `calculatePhase`,
  `calculateDaysUntilPeriod`
- **logs.dailyLogs**: подробная запись за день — кровотечение (объём, прокладки, цвет, сгустки),
  боль (уровень 0–5, тип, локализация, иррадиация, влияние на жизнь, обезболивающее + помогло ли),
  настроение, энергия, сон (качество, часы, пробуждения и причины), кожа (акне и количество,
  сухость, жирность, выпадение волос), либидо, контекст, заметка; плюс `selfCare` (вода, калории,
  БЖУ, ходьба, тренировка, вес, витамины). → `setDailyLog`, `addDailyLog`, `updateDailyLog`,
  `getLogByDate`, `getLogsByCycle`
- **care**: вода (текущее/цель), витамины (магний, омега-3, цинк), история веса, активность. →
  `setWater`, `addWater`, `setVitamin`, `setWeight`
- **settings**: напоминания (вода, лог, витамины), приватность (PIN + код, хранение device/cloud),
  достижения. → `toggleReminder`, `togglePin`, `unlockAchievement`, `updateAchievementProgress`
- **ui**: загрузка, открыт ли PainModal, активная вкладка, уведомления. → `setLoading`,
  `setActiveTab`, `openPainModal`, `closePainModal`, `addNotification`, `markNotificationRead`,
  `clearNotifications`

### 3.2 Legacy-слой `MiraLocalData` (`lib/store.ts`, `lib/types.ts`)
Используется модалками CheckIn/BadState/DelayCheck и всей аналитикой на `lib/*`: `readData`,
`writeData`, `clearData`, `saveCheckIn`, `getCheckIn`, `addWorkout`, `saveProfile`,
`saveIslamicEntry`, `getIslamicEntry`, `countQadaDays`, `countHaydDays`, `isInHayd`, `dateKey`.
Содержит `UserProfile.additionalMode: "none" | "islam"`.

## 4. Доменная логика (`lib/`)

**Цикл и прогнозы**
- `cycleEngine.ts` — личная норма цикла (`getCycleNorm`), прогноз месячных (`getPeriodForecast`),
  фиксация начала цикла (`recordPeriodStart`)
- `cycleAnalytics.ts` — сводная аналитика по циклам
- `cycleDisplay.ts` — форматирование дня/фазы для UI
- `dailyLog.ts` — ключ сегодняшнего дня, создание/сборка/**слияние** дневной записи
  (`mergeDailyLogPartial` — критично: не даёт модалкам затирать данные друг друга)

**Аналитика и инсайты**
- `insights.ts` — микроинсайт по чек-ину, карта нормы (`getNormMap`, `getNormOverallPercent`),
  прогноз на завтра (`getDayPrediction`), сводка цикла (`getCycleSummary`), умные инсайты
- `correlations.ts` — корреляции между симптомами
- `alerts.ts` (704 строки) — умные напоминания, связь секса и цикла, **красные флаги**
  (`getRedFlags`), фазовые корреляции, железо/анемия (`getIronAlert`), «тяжёлый день»
  (`isToughDay`, `getToughDayContent`), скрипт разговора с врачом
- `healthScore.ts` — метрики здоровья со статусами `ok|watch|concern|nodata`
- `moodPms.ts` — карточка настроения/ПМС по фазе
- `workMode.ts` — режим работы/нагрузки по фазе

**Забота и рекомендации**
- `vitamins.ts` — рекомендации витаминов
- `workouts.ts` — генерация тренировки (`generateWorkout`) и статистика
- `periodKit.ts` — чек-лист «аптечка» (прокладки, обезболивающее, тест на беременность)
- `tips.ts` — совет дня по фазе
- `labs.ts` — каталог анализов с референсами, оценка результата (`evaluateLab`), гормональный
  чек-ап 45+, рекомендации, добавление/удаление результатов

**Адаптации**
- `ageMode.ts` — возрастные группы `teen|young|mature|peri`, скрытие тем (фертильность, секс) для
  подростков, свои карточки фаз
- `ageHealthGuidance.ts` — рекомендации по возрастным группам, включая `menopause_50_64`
- `islamic.ts` — 4 мазхаба, статус дня (`hayd|istihada|nifas|purity`), советы по кровотечению,
  статистика када, необходимость гусля, дуа, информация о Рамадане, обучающие карточки

**Геймификация**
- `gamification.ts` — стрик, «сад» (стадии роста), ежедневный ритуал, достижения и счётчик

**Приватность, синхронизация, уведомления**
- `privacy.ts` — категории облачной синхронизации, партнёрский доступ, PIN (сохранение, проверка,
  сброс), очистка данных перед отправкой в облако (`sanitizeForCloud`)
- `sync.ts` — Supabase-синхронизация: push/pull, синк при загрузке, отложенный push
- `supabase.ts` — клиент
- `notifications.ts` — поддержка/разрешения/включение уведомлений, ежедневное уведомление
- `personalReminders.ts` — каталог персональных напоминаний, настройки, тексты уведомлений
  (в т.ч. «тихий» вариант формулировки)
- `services/reminder.service.ts` — планирование напоминаний (вызывается при смене маршрута)

## 5. Экраны и их функциональность

- **TodayPage** — день/фаза цикла, кольцо цикла, 4 быстрых действия (боль, начало месячных,
  симптом, отчёт врачу), виджеты воды/питания/витаминов/шагов, календарь месяца с типами дней
  (месячные/ПМС/обычный/заметка), карточка «первая польза» (первые закономерности с честным
  порогом в 3 отметки), предупреждение о необходимости обратиться к врачу при боли ≥4 или обильном
  кровотечении, переход в Заботу
- **CarePage** — вода, витамины (магний+B6, омега-3, цинк с пояснениями), вес, активность
  (ходьба/тренировка), аптечка-чеклист, кожа
- **AnalyticsPage** (1075 строк) — графики recharts (длина цикла, тренды), вкладки периодов
  (текущий/3/6/12 месяцев), корреляции («мало воды → головная боль»), «как обычно у тебя»,
  «когда не стоит терпеть», честные пороги («блок появится после 3 отметок», «малая выборка: это
  наблюдение, не вывод»), экспорт/отчёт
- **ReportScreen** (1199 строк) — отчёт врачу: выбор периода, проверка приватности, главное для
  врача, даты месячных, длина цикла, боль и симптомы, задержки, анализы вне референса, вопросы
  врачу, детали по дням, скачивание PDF/TXT
- **ProfilePage** — профиль, настройки цикла, метрики, список анализов, достижения, push-уведомления,
  выбор хранения (только устройство / с резервной копией), удаление всех данных
- **ContentPage / ArticlePage** — лента статей по категориям (сегодня/цикл/забота/врач/новости),
  поиск, закладки, чтение
- **DiaryScreen** — дневник: отметки месячных, боли, настроения, сна, энергии, заметок
- **IslamicScreen** — статусы (менструация/истихада/послеродовое/чистота), пост, каза, освобождение
- **LabsScreen / LabsSection** — хранение и оценка результатов анализов, вопросы врачу

**Модалки ввода**
- **QuickTrackModal** — быстрая отметка: месячные, боль 0–5, настроение, энергия, сон, заметка
- **PainModal** — 3 шага: что случилось (мультивыбор) → сила 1–5 → что уже сделала; выдаёт
  рекомендацию по правилам (включая эскалацию «обратись к врачу без записи») и сохраняет в дневник
- **CheckInModal** — расширенный чек-ин с сеткой категорий
- **BadStateModal** — состояние «плохо»
- **DelayCheckModal** — проверка задержки

**Карточки/виджеты**: CycleWheel (кольцо фаз), DayPrediction (прогноз на завтра), CycleSummaryCard,
HealthDashboard (кольца метрик + спарклайны), NormMap (карта личной нормы), GardenCard (сад/стрик),
AchievementsCard, NormaScanCard, MiraWidget (настроение + стрик), CountUp.

## 7. Продуктовые ограничения (из AGENTS.md — обязательны к сохранению)

- Не подавать диагнозы, фертильность, беременность и заболевания как факт
- Эскалация формулируется как «стоит обсудить с квалифицированным врачом»
- Не рекомендовать лекарства и добавки как лечение
- Снижать интенсивность нагрузки при боли
- Честность про недостаток данных вместо красивых пустых графиков
